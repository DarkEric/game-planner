# 🎲 Game Planner

[English version](README.en.md) | Русская версия | **[📖 Документация](docs/INDEX.md)**

Веб-приложение для планирования настольных игр с друзьями. Отмечайте свободное время, находите общие слоты и планируйте игры вместе!

> **Новичок?** Начните с [простого гайда](docs/guides/SIMPLE_GUIDE.md) - всё объяснено простым языком!  
> **Вся документация:** [docs/INDEX.md](docs/INDEX.md)

## ✨ Возможности

### Основной функционал
- 📅 **Интерактивный календарь** - отмечайте доступное время drag-and-drop
- 🎯 **Умный поиск слотов** - автоматический поиск лучшего времени для всех
- 🎮 **Планирование игр** - создавайте игры с названием, описанием и участниками
- 👥 **Управление участниками** - установка лимита участников, автоматическое добавление, удаление игроков
- 🌍 **Поддержка часовых поясов** - каждый видит время в своем часовом поясе
- 🔐 **Система инвайтов** - регистрация только по приглашениям

### Управление кампаниями
- 🎲 **Система кампаний** - создание и управление настольными кампаниями
- 🎯 **Система вех (milestones)** - отслеживание прогресса кампании
- 👤 **Управление персонажами** - создание и редактирование персонажей для кампаний
- 🎭 **Система ролей** - мастер (GM) и игроки с разными правами доступа
- 📝 **Приглашения в кампании** - система приглашений с созданием персонажей
- 🔗 **Связывание игр** - привязка игр к кампаниям

### Администрирование
- 👨‍💼 **Админ-панель** - управление пользователями (удаление, назначение прав)
- 🔐 **Сброс пароля** - восстановление доступа через Telegram бота

### Уведомления
- 📱 **Telegram уведомления** - уведомления о новых играх, отменах, удалении из игры
- 🤖 **Telegram бот** - запись на игры и выход из них прямо из Telegram, получение списка предстоящих игр
- ⚙️ **Персональные настройки** - гибкая настройка уведомлений для каждого пользователя
- ⏰ **Напоминания** - персональные и групповые напоминания о разметке времени (cron-поддержка)
- 🎯 **Топики Telegram** - отправка уведомлений в конкретные топики супергрупп

### Интерфейс
- 🎨 **Темная тема** - приятный интерфейс для глаз
- 📱 **Адаптивный дизайн** - работает на любых экранах
- 📊 **Адаптивный календарь** - автоматически подстраивается под ширину экрана (7-21 день)

## 🚀 Быстрый старт

### Требования

- Docker и Docker Compose
- Git

### Вариант 1: Готовые Docker образы (Рекомендуется)

Используйте предсобранные образы из GitHub Container Registry:

```bash
git clone https://github.com/DarkEric/game-planner.git
cd game-planner
copy .env.example .env
docker-compose -f docker-compose.ghcr.yml up -d
```

### Вариант 2: Сборка из исходников

1. Клонируйте репозиторий:
```bash
git clone https://github.com/DarkEric/game-planner.git
cd game-planner
```

2. Создайте файл `.env` из примера:
```bash
copy .env.example .env
```

3. Запустите приложение:
```bash
# Windows
start.bat

# Linux/Mac
docker-compose up -d
```

4. Откройте в браузере: http://localhost

📦 **Подробнее о Docker образах:** [DOCKER_IMAGES.md](DOCKER_IMAGES.md)

### Первый запуск

При первом запуске используйте инвайт-код для регистрации:
```
FIRST-USER-INVITE-2025
```

После регистрации вы сможете создавать новые инвайт-коды для друзей.

## 📖 Использование

### Отметка доступного времени

1. Войдите в систему
2. Кликните или протяните мышью по ячейкам календаря
3. Ваше время автоматически сохранится

### Планирование игры

1. Нажмите кнопку "🎲 Запланировать игру"
2. Выберите время из топ-10 лучших слотов или укажите вручную
3. Добавьте название и описание (опционально)
4. Установите максимальное количество участников (опционально)
5. Выберите автоматическое добавление игроков (опционально)
6. Привяжите игру к кампании (опционально)
7. Игра создастся с участниками, у которых есть доступность на это время

### Управление кампаниями

1. Перейдите в раздел "Кампании"
2. Создайте новую кампанию с названием, описанием и количеством вех
3. Пригласите игроков в кампанию
4. Игроки создают персонажей при принятии приглашения
5. Связывайте игры с кампаниями при планировании
6. Отслеживайте прогресс через систему вех

### Управление участниками игры

- **Организатор игры** может:
  - Удалять игроков из игры
  - Устанавливать лимит участников
  - Автоматически добавлять выбранных игроков при создании
- **Игроки** могут:
  - Записываться на игру
  - Покидать игру

### Управление инвайтами

1. В разделе "Мои инвайт-коды" нажмите "+ Создать инвайт"
2. Скопируйте код и отправьте другу
3. Каждый инвайт одноразовый

## 🔧 Конфигурация

### Переменные окружения

Создайте `.env` файл в корне проекта (см. `.env.example`):

```env
# Database
POSTGRES_DB=game_planner
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_secure_password

# Backend
JWT_SECRET=your_jwt_secret_key_here_min_256_bits
SPRING_PROFILES_ACTIVE=prod
CORS_ALLOWED_ORIGINS=http://localhost:5173,http://localhost:3000,http://localhost

# Cleanup
CLEANUP_ENABLED=true
CLEANUP_RETENTION_DAYS=15
CLEANUP_CRON=0 0 3 * * ?

# Telegram (опционально)
TELEGRAM_BOT_ENABLED=false
TELEGRAM_BOT_TOKEN=
TELEGRAM_BOT_CHAT_ID=
TELEGRAM_BOT_THREAD_ID=
TELEGRAM_BOT_TIMEZONE=Europe/Moscow
FRONTEND_URL=http://localhost:5173
TELEGRAM_NOTIFICATIONS_SCHEDULED_ENABLED=true
TELEGRAM_NOTIFICATIONS_CHECK_INTERVAL=60000
TELEGRAM_GROUP_TIME_SLOT_REMINDER_ENABLED=false
TELEGRAM_GROUP_TIME_SLOT_REMINDER_CRON=

# Frontend
VITE_API_URL=http://localhost:8080
```

### Production deployment

Для production используйте `docker-compose.prod.yml`:

```bash
docker-compose -f docker-compose.prod.yml up -d
```

### Использование Makefile

Для удобства управления проектом доступны Make команды:

```bash
make build              # Собрать Docker образы
make up                 # Запустить приложение
make down               # Остановить приложение
make restart            # Перезапустить приложение
make logs               # Показать логи
make clean              # Удалить контейнеры и volumes
make dev                # Запустить в режиме разработки
make prod               # Запустить в production режиме
make external-caddy     # Запустить с внешним Caddy
```

Подробнее см. [docs/setup/PRODUCTION_SETUP.md](docs/setup/PRODUCTION_SETUP.md)

## 📱 Telegram уведомления

Game Planner поддерживает отправку уведомлений в Telegram при создании новых игр, отменах, удалении из игры и напоминаниях.

### Быстрая настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен и Chat ID
3. Добавьте в `.env`:
```env
TELEGRAM_BOT_ENABLED=true
TELEGRAM_BOT_TOKEN=ваш_токен
TELEGRAM_BOT_CHAT_ID=ваш_chat_id
TELEGRAM_BOT_THREAD_ID=  # Опционально, для топиков в супергруппах
TELEGRAM_BOT_TIMEZONE=Europe/Moscow  # Часовой пояс для уведомлений
FRONTEND_URL=http://localhost:5173
```
4. Перезапустите приложение

### Возможности

#### Уведомления
- 🔔 Уведомления о новых играх с inline-клавиатурой для быстрого присоединения
- ❌ Уведомления об отмене игр с указанием причины
- 👋 Уведомления об удалении из игры
- ⏰ Персональные напоминания о разметке времени (настраиваемые через cron)
- 📢 Групповые напоминания о временных слотах
- 🎯 Отправка в топики супергрупп Telegram
- ⚙️ Гибкие настройки уведомлений для каждого пользователя

#### Команды бота

**Основные команды:**
- `/start` - Начать работу с ботом
- `/menu` - Главное меню с быстрым доступом ко всем функциям
- `/help` - Показать справку по командам
- `/stop` - Отписаться от уведомлений

**Игры:**
- `/games` - Список всех предстоящих игр на 60 дней вперед
- `/game <id>` - Детальная информация об игре по ID
- Запись на игры и выход из игр через inline-клавиатуру в меню

**Регистрация и авторизация:**
- `/register` - Регистрация нового аккаунта через бота
- `/auth` - Авторизация существующего аккаунта через логин/пароль
- `/link <token>` - Привязка Telegram аккаунта к существующему аккаунту через токен
- `/cancel` - Отмена текущей операции (регистрации/авторизации)

**Временные слоты:**
- `/mark` - Разметить доступное время для игр
- `/myslots` - Показать мои размеченные временные слоты

**Инвайт-коды:**
- `/invite` - Создать новый инвайт-код для регистрации друзей
- `/myinvites` - Показать список моих инвайт-кодов

**Через меню доступны:**
- 🎮 Управление играми (просмотр, запись, выход)
- ⏰ Разметка времени с выбором дат
- ⚙️ Настройки уведомлений (включить/выключить типы уведомлений)
- 🌍 Изменение часового пояса
- 📋 Управление инвайт-кодами
