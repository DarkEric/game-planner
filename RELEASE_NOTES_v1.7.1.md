# 🎉 Game Planner v1.7.1 - UI Improvements & Bug Fixes

**Release Date:** January 2025

## 🆕 Что нового

### 👥 Улучшенное отображение информации об игроках

**Информация о количестве участников:**
- Теперь видно максимальное и текущее количество игроков во всех местах интерфейса
- Отображение в формате "X/Y игроков" когда задан максимум, или "X игроков" когда максимума нет
- Создатель игры не учитывается в подсчете участников
- Информация отображается в:
  - Деталях игры (модальное окно)
  - Событиях на календаре
  - Списке игр в кампании
  - Модальном окне привязки игры к кампании

**Улучшенная карточка игры:**
- Добавлен отдельный пункт "Максимум участников" в деталях игры
- Более заметное отображение информации о заполненности игры
- Индикация "Заполнена" когда достигнут лимит участников

### 📅 Улучшения календаря

**Более широкие ячейки времени:**
- Ширина ячеек календаря увеличена в 2 раза (с 80px до 160px)
- Улучшена читаемость и удобство использования
- Автоматический пересчет количества отображаемых дней

**Многострочное описание событий:**
- Описание игр в календаре теперь отображается многострочно
- Ограничено 3 строками с автоматическим обрезанием
- Улучшена читаемость длинных описаний

### 🐛 Исправления

**Исправлена передача данных:**
- Исправлена передача `maxParticipants` в методе `getGames` API
- Теперь `maxParticipants` корректно отображается во всех компонентах
- Исправлен дубликат поля `participants` в `getMyGames`

**Улучшена логика подсчета:**
- Создатель игры правильно исключается из подсчета участников во всех местах
- Улучшена проверка наличия `maxParticipants` (убрана излишняя проверка на > 0)

## 🔧 Технические улучшения

**Frontend (React):**
- Обновлен `GameDetails.jsx` с улучшенным отображением информации об игроках
- Обновлен `CalendarTimeline.jsx` с многострочным описанием
- Обновлен `CalendarTab.jsx` для корректного отображения количества игроков
- Обновлен `CampaignDetails.jsx` с информацией о количестве игроков
- Исправлен `gameApi.js` для передачи всех необходимых полей

**CSS:**
- Увеличена ширина ячеек календаря в `CalendarTimeline.css`
- Добавлено многострочное отображение описания с ограничением по высоте
- Обновлен расчет количества дней в `App.jsx`

## 🔄 Обновление с 1.7.0

### Для пользователей Docker Compose

```bash
# 1. Обновите код
git pull origin main

# 2. Пересоберите контейнеры
docker-compose down
docker-compose up -d --build
```

### Для пользователей готовых образов

```bash
# 1. Обновите код
git pull origin main

# 2. Используйте новые образы
docker-compose -f docker-compose.ghcr.yml pull
docker-compose -f docker-compose.ghcr.yml up -d
```

### Миграция базы данных

Все изменения обратно совместимы. Новые миграции не требуются.

## 💡 Примеры использования

### Просмотр информации об игроках

1. Откройте календарь - увидите количество игроков в каждом событии
2. Кликните на игру - в деталях увидите полную информацию
3. В кампании - информация о количестве игроков в каждой игре

### Работа с лимитом участников

1. При создании игры укажите максимальное количество участников
2. В календаре будет видно, сколько мест свободно (например, "3/5 игроков")
3. Когда игра заполнена, кнопка "Записаться" будет неактивна
