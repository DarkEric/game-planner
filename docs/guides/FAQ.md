# ❓ Часто задаваемые вопросы (FAQ)

## Общие вопросы

### Что такое Game Planner?
Приложение для планирования настольных игр. Каждый отмечает когда свободен, приложение находит лучшее время для всех.

### Это бесплатно?
Да, полностью бесплатно и open-source.

### Нужна ли регистрация?
Да, но только по инвайт-кодам. Первый код: `FIRST-USER-INVITE-2025`

### Работает ли на телефоне?
Да, интерфейс адаптивный и работает на любых устройствах.

## Установка и запуск

### Что нужно для запуска?
Только Docker Desktop. Скачайте с https://www.docker.com/products/docker-desktop

### Как запустить?
```bash
git clone https://github.com/DarkEric/game-planner.git
cd game-planner
docker-compose up -d
```
Откройте http://localhost

### Приложение не запускается
```bash
docker-compose down -v
docker-compose up -d
```

### Порт 80 занят
Измените в `docker-compose.yml`:
```yaml
caddy:
  ports:
    - "8080:80"
```
Откройте http://localhost:8080

### Как обновить до новой версии?
```bash
git pull
docker-compose down
docker-compose up -d --build
```

## Использование

### Как отметить свободное время?
Кликните или протяните мышью по ячейкам календаря.

### Как снять отметку?
Кликните на отмеченную ячейку повторно.

### Как пригласить друга?
"Мои инвайт-коды" → "+ Создать инвайт" → Скопируйте код → Отправьте другу.

### Сколько инвайтов можно создать?
Неограниченно. Каждый инвайт одноразовый.

### Как создать игру?
1. Отметьте свободное время
2. Нажмите "Запланировать игру"
3. Выберите время из топ-10 или укажите вручную
4. Добавьте название и описание
5. Нажмите "Запланировать игру"

### Почему не вижу кнопку "Запланировать игру"?
Сначала отметьте хотя бы один свободный слот в календаре.

### Как записаться на игру?
Кликните на игру в календаре → "Записаться на игру".

### Как покинуть игру?
Кликните на игру → "Покинуть игру".

### Как удалить игру?
Кликните на игру → "Удалить игру" (только для создателя).

### Можно ли указать причину отмены?
Да, при удалении появится диалог для ввода причины.

### Что такое "Топ-10 лучших слотов"?
Приложение автоматически находит время, когда доступно больше всего игроков.

### Как изменить часовой пояс?
Нажмите на выпадающий список "Часовой пояс" в профиле.

### Как изменить цвет?
Нажмите на цветной квадрат в профиле.

### Как изменить имя?
Введите новое имя в поле "Имя" и нажмите Enter.

## Часовые пояса

### Почему время отличается у разных игроков?
Каждый видит время в своем часовом поясе. Это нормально.

### Как работает автоопределение часового пояса?
Приложение определяет часовой пояс из настроек браузера.

### Можно ли изменить часовой пояс?
Да, в профиле выберите нужный из списка.

### Поддерживается ли летнее время?
Да, автоматически.

## Игры

### Сколько игроков может быть в игре?
Неограниченно.

### Можно ли изменить игру после создания?
Пока нет, только удалить и создать заново.

### Сколько хранятся старые игры?
15 дней (настраивается). После этого удаляются автоматически.

### Можно ли отключить автоудаление?
Да, в `.env` установите `CLEANUP_ENABLED=false`.

### Как изменить срок хранения игр?
В `.env` измените `CLEANUP_RETENTION_DAYS=30` (например, на 30 дней).

## Telegram уведомления

### Как включить Telegram уведомления?
См. [TELEGRAM_QUICK_START.md](TELEGRAM_QUICK_START.md) - там всё за 3 шага.

### Обязательно ли настраивать Telegram?
Нет, это опциональная функция.

### Какие уведомления отправляются?
- Создание новой игры
- Отмена игры (с причиной)

### Можно ли отправлять в группу?
Да, укажите Chat ID группы.

### Можно ли отправлять в конкретный топик?
Да, укажите Thread ID. См. [docs/TELEGRAM_TOPICS.md](docs/TELEGRAM_TOPICS.md)

### Время в уведомлениях неправильное
Настройте часовой пояс в `.env`:
```env
TELEGRAM_BOT_TIMEZONE=Europe/Moscow
```
См. [docs/TELEGRAM_TIMEZONE.md](docs/TELEGRAM_TIMEZONE.md)

### Уведомления не приходят
1. Проверьте `TELEGRAM_BOT_ENABLED=true`
2. Проверьте токен и Chat ID
3. См. [docs/TELEGRAM_DEBUG.md](docs/TELEGRAM_DEBUG.md)

## Безопасность

### Безопасно ли приложение?
Да:
- JWT аутентификация
- Пароли хешируются
- HTTPS в production (через Caddy)
- Регистрация только по инвайтам

### Где хранятся данные?
В PostgreSQL базе данных внутри Docker контейнера.

### Можно ли сделать бэкап?
Да:
```bash
docker exec game-planner-db pg_dump -U postgres game_planner > backup.sql
```

### Как восстановить из бэкапа?
```bash
docker exec -i game-planner-db psql -U postgres game_planner < backup.sql
```

## Production

### Как запустить в продакшене?
См. [PRODUCTION_SETUP.md](PRODUCTION_SETUP.md)

### Нужен ли SSL сертификат?
Нет, Caddy получает его автоматически (Let's Encrypt).

**⚠️ ВАЖНО:** Укажите свой email в `Caddyfile.prod`, иначе сертификат не будет получен!

### Почему не получается получить SSL сертификат?
**Самая частая причина:** Не указан email в `Caddyfile.prod`

Откройте файл:
```bash
nano Caddyfile.prod
```

Измените:
```caddyfile
{
    email your-email@example.com  # ← Укажите ВАШУ почту!
}
```

Перезапустите:
```bash
docker-compose -f docker-compose.prod.yml down
docker-compose -f docker-compose.prod.yml up -d
```

### Какие порты нужно открыть?
- 80 (HTTP)
- 443 (HTTPS)

### Как настроить домен?
1. Создайте A-запись: ваш-домен.com → IP сервера
2. В `.env` укажите `DOMAIN=ваш-домен.com`
3. Запустите `docker-compose -f docker-compose.prod.yml up -d`

### Сколько нужно ресурсов?
Минимум:
- 1 CPU
- 1 GB RAM
- 10 GB диск

Рекомендуется:
- 2 CPU
- 2 GB RAM
- 20 GB диск

## Разработка

### Как запустить для разработки?
```bash
# Backend
cd game-planner-back
./gradlew bootRun

# Frontend
cd game-planer-front
npm install
npm run dev
```

### Какие технологии используются?
- Backend: Java 21 + Spring Boot
- Frontend: React 18 + Vite
- Database: PostgreSQL 17
- Reverse Proxy: Caddy 2

## Проблемы

### Забыл пароль
Создайте новый аккаунт с новым инвайт-кодом.

### Потерял инвайт-код
Попросите у того, кто вас пригласил, создать новый.

### База данных повреждена
```bash
docker-compose down -v
docker-compose up -d
```
⚠️ Это удалит все данные!

### Приложение тормозит
```bash
docker-compose restart
```

### Ошибка "Out of memory"
Увеличьте память для Docker в настройках Docker Desktop.

### Не работает после обновления
```bash
docker-compose down
docker-compose up -d --build
```
