# 🎲 Game Planner - Простой гайд

## Что это?

Приложение для планирования настольных игр с друзьями. Каждый отмечает когда свободен, приложение находит лучшее время для всех.

## Быстрый старт (5 минут)

### 1. Установка

**Что нужно:**
- Docker Desktop (скачать с https://www.docker.com/products/docker-desktop)

**Запуск:**

```bash
# Скачайте проект
git clone https://github.com/DarkEric/game-planner.git
cd game-planner

# Запустите
docker-compose up -d
```

Откройте http://localhost

### 2. Первый вход

Используйте инвайт-код: `FIRST-USER-INVITE-2025`

Создайте аккаунт и войдите.

### 3. Как пользоваться

**Шаг 1: Отметьте свободное время**
- Кликните или протяните мышью по календарю
- Ваше время сохранится автоматически

**Шаг 2: Пригласите друзей**
- Нажмите "Мои инвайт-коды" → "Создать инвайт"
- Скопируйте код и отправьте друзьям

**Шаг 3: Запланируйте игру**
- Нажмите "Запланировать игру"
- Выберите время из топ-10 лучших слотов
- Добавьте название (например, "D&D Session")
- Готово!

## Основные функции

### 📅 Календарь
- **Клик** - отметить 1 час
- **Протянуть мышью** - отметить несколько часов
- **Повторный клик** - снять отметку

### 🎯 Топ-10 слотов
Приложение автоматически находит лучшее время, когда доступно больше всего игроков.

### 🎮 Игры
- **Создать** - только вы можете создавать игры
- **Записаться** - другие могут присоединиться
- **Удалить** - только создатель может удалить

### 🔐 Инвайты
- Каждый инвайт одноразовый
- Создавайте новые для каждого друга
- Можно удалить неиспользованные

## Часто задаваемые вопросы

### Как изменить свой часовой пояс?
Нажмите на выпадающий список "Часовой пояс" в профиле.

### Как удалить игру?
Откройте детали игры → "Удалить игру" (только для создателя).

### Почему я не вижу кнопку "Запланировать игру"?
Сначала отметьте хотя бы один свободный слот в календаре.

### Как покинуть игру?
Откройте детали игры → "Покинуть игру".

### Сколько хранятся старые игры?
Игры старше 15 дней удаляются автоматически.

## Telegram уведомления (опционально)

Хотите получать уведомления о новых играх в Telegram?

### Быстрая настройка

1. **Создайте бота:**
   - Откройте [@BotFather](https://t.me/BotFather)
   - Отправьте `/newbot`
   - Сохраните токен

2. **Получите Chat ID:**
   - Отправьте боту `/start`
   - Откройте: `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   - Найдите `"chat":{"id":123456789}`

3. **Настройте:**
   - Создайте файл `.env` (скопируйте из `.env.example`)
   - Добавьте:
     ```env
     TELEGRAM_BOT_ENABLED=true
     TELEGRAM_BOT_TOKEN=ваш_токен
     TELEGRAM_BOT_CHAT_ID=ваш_chat_id
     ```

4. **Перезапустите:**
   ```bash
   docker-compose down
   docker-compose up -d
   ```

Готово! Теперь при создании игры придет уведомление.

**Подробнее:** [TELEGRAM_QUICK_START.md](TELEGRAM_QUICK_START.md)

## Устранение проблем

### Приложение не запускается

```bash
# Остановите и удалите контейнеры
docker-compose down -v

# Запустите заново
docker-compose up -d
```

### Порт 80 занят

Измените порт в `docker-compose.yml`:
```yaml
caddy:
  ports:
    - "8080:80"  # Вместо "80:80"
```

Откройте http://localhost:8080

### Забыли пароль

Создайте новый аккаунт с новым инвайт-кодом.

### База данных не работает

```bash
docker-compose down -v
docker-compose up -d
```

⚠️ **Внимание:** Это удалит все данные!

## Production (для продакшена)

### Минимальная настройка

1. **Создайте `.env`:**
   ```env
   POSTGRES_PASSWORD=сложный_пароль
   JWT_SECRET=случайная_строка_минимум_256_бит
   CORS_ALLOWED_ORIGINS=https://ваш-домен.com
   DOMAIN=ваш-домен.com
   ```

2. **Запустите:**
   ```bash
   docker-compose -f docker-compose.prod.yml up -d
   ```

3. **Настройте DNS:**
   - A-запись: ваш-домен.com → IP сервера

4. **Откройте порты:**
   - 80 (HTTP)
   - 443 (HTTPS)

Caddy автоматически получит SSL сертификат.

**Подробнее:** [PRODUCTION_SETUP.md](PRODUCTION_SETUP.md)
