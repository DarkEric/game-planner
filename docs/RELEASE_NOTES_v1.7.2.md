## Технические детали

### Алгоритм распределения по колонкам

1. События сортируются по времени начала
2. Для каждого события определяется первая свободная колонка
3. Колонка считается свободной, если в ней нет событий, перекрывающихся по времени
4. Если все колонки заняты, создается новая колонка
5. Для многочасовых игр сохраняется одна и та же колонка на всех часах перекрытия

### Проверка перекрытия событий

События считаются перекрывающимися, если:
- `event1.start < event2.end && event2.start < event1.end`

Это учитывает все случаи:
- Событие A начинается до B, но продолжается во время B
- Событие A начинается во время B
- Событие A полностью внутри B
- Событие A полностью содержит B

## Известные ограничения

- При большом количестве перекрывающихся игр (более 3) требуется горизонтальная прокрутка
- Минимальная ширина колонки ограничена 50px для читаемости
