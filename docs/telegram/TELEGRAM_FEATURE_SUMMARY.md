# 📱 Telegram уведомления - Что добавлено

## Новая функциональность

Теперь Game Planner может отправлять уведомления в Telegram при создании новых игр!

### Что происходит

Когда кто-то создает новую игру, в указанный Telegram чат/канал автоматически отправляется красивое уведомление с:
- 🎮 Названием и описанием игры
- 🕐 Временем проведения
- 👤 Именем организатора
- 👥 Количеством участников
- 🔗 Прямой ссылкой на игру

## Как включить

### Быстрый старт (3 шага)

1. **Создайте бота** через [@BotFather](https://t.me/BotFather)
2. **Получите Chat ID** (инструкция в [TELEGRAM_QUICK_START.md](TELEGRAM_QUICK_START.md))
3. **Добавьте в .env**:
   ```env
   TELEGRAM_BOT_ENABLED=true
   TELEGRAM_BOT_TOKEN=ваш_токен
   TELEGRAM_BOT_CHAT_ID=ваш_chat_id
   FRONTEND_URL=http://localhost:5173
   ```

### Перезапуск

```bash
docker-compose down
docker-compose up -d --build
```

## Особенности

### ✅ Безопасность
- Функция опциональная (по умолчанию выключена)
- Токены хранятся в переменных окружения
- Не коммитятся в Git

### ✅ Надежность
- Ошибки отправки не ломают создание игры
- Логирование всех операций
- Graceful degradation

### ✅ Гибкость
- Работает с личными чатами
- Работает с группами
- Работает с каналами
- Настраиваемый URL фронтенда

## Примеры использования

### Для личного использования
Отправляйте уведомления себе в личные сообщения

### Для команды
Создайте группу в Telegram и получайте уведомления всей командой

### Для сообщества
Создайте канал и делитесь анонсами игр с подписчиками

## Отключение

Чтобы отключить уведомления:

```env
TELEGRAM_BOT_ENABLED=false
```

Или просто удалите/закомментируйте переменные в `.env`
