# Функция видимости всех кампаний и приглашений

## Описание
Реализована система, где все кампании видны всем пользователям, с возможностью приглашения игроков мастером.

## Изменения

### Backend

#### Новые сущности
- **CampaignInvite** - приглашения в кампанию с статусами (PENDING, ACCEPTED, DECLINED)

#### Репозитории
- **CampaignRepository** - добавлен метод `findAllOrderedByStatus()` для получения всех кампаний с сортировкой по статусу
- **CampaignInviteRepository** - новый репозиторий для работы с приглашениями

#### DTO
- **CampaignDto** - добавлены поля `hasInvite`, `isPlayer`, `isCreator` для отображения статуса пользователя
- **CampaignInviteDto** - новый DTO для приглашений

#### CampaignService
- `getUserCampaigns()` - теперь возвращает все кампании (сортировка: ACTIVE → ON_HOLD → COMPLETED)
- `invitePlayerToCampaign()` - отправка приглашения игроку
- `acceptCampaignInvite()` - принятие приглашения с заполнением информации о персонаже
- `declineCampaignInvite()` - отклонение приглашения
- `getPendingInvites()` - получение ожидающих приглашений для пользователя
- `getCampaignInvites()` - получение всех приглашений кампании (для мастера)

#### CampaignController
- Добавлены эндпоинты для работы с приглашениями:
  - `POST /{id}/invites` - пригласить игрока
  - `GET /{id}/invites` - получить приглашения кампании
  - `GET /invites/pending` - получить свои ожидающие приглашения
  - `POST /invites/{inviteId}/accept` - принять приглашение
  - `POST /invites/{inviteId}/decline` - отклонить приглашение

#### База данных
- Миграция `012-create-campaign-invites.xml` - создание таблицы campaign_invites

### Frontend

#### campaignApi.js
- Добавлены методы для работы с приглашениями

#### CampaignList.jsx
- Отображение всех кампаний для всех пользователей
- Индикаторы:
  - 👑 - пользователь является создателем
  - 🎭 - пользователь является игроком
  - ✉️ - есть ожидающее приглашение
- Подсветка кампаний с приглашениями

#### CampaignDetails.jsx
- Баннер приглашения для приглашенных пользователей
- Кнопка "Пригласить игрока" для мастера
- Модальное окно выбора игрока для приглашения
- Модальное окно принятия приглашения с заполнением информации о персонаже:
  - Имя персонажа (обязательно)
  - Класс/Роль (необязательно)
  - Заметки о персонаже (необязательно)

## Использование

### Для мастера:
1. Откройте детали кампании
2. В секции "Постоянные игроки" нажмите "+ Пригласить игрока"
3. Выберите игрока из списка
4. Игрок получит приглашение

### Для игрока:
1. В списке кампаний видны все кампании
2. Кампании с приглашениями подсвечены и имеют иконку ✉️
3. Откройте кампанию с приглашением
4. Нажмите "Принять приглашение"
5. Заполните информацию о персонаже
6. Нажмите "Присоединиться"

## Сортировка кампаний
Кампании отображаются в порядке:
1. ACTIVE (Активные) - 🟢
2. ON_HOLD (На паузе) - ⏸️
3. COMPLETED (Завершенные) - ✅
