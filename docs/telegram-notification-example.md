# Пример Telegram уведомления

Когда создается новая игра, в Telegram отправляется уведомление следующего формата:

## Формат сообщения

```
🎮 Новая игра запланирована!

📌 D&D Session #42
📝 Продолжаем кампанию "Проклятие Страда". Не забудьте свои дайсы!

🕐 Время: 17.11.2025 18:00 - 17.11.2025 21:00
👤 Организатор: Иван Иванов
👥 Участники: 4

🔗 Открыть игру
```

## Элементы уведомления

- **🎮 Заголовок** - всегда "Новая игра запланирована!"
- **📌 Название** - название игры (если указано)
- **📝 Описание** - описание игры (если указано)
- **🕐 Время** - дата и время начала и окончания
- **👤 Организатор** - имя создателя игры
- **👥 Участники** - количество участников
- **🔗 Ссылка** - прямая ссылка на игру в приложении

## Особенности

- Сообщение форматируется с использованием HTML разметки
- Ссылка ведет напрямую на страницу игры с параметром `?gameId=X`
- Время отображается в системном часовом поясе сервера
- Специальные символы HTML экранируются для безопасности

## Пример минимального уведомления

Если игра создана без названия и описания:

```
🎮 Новая игра запланирована!

🕐 Время: 17.11.2025 18:00 - 17.11.2025 21:00
👤 Организатор: Иван Иванов
👥 Участники: 2

🔗 Открыть игру
```

## Настройка формата

Формат уведомления можно изменить в файле:
`game-planner-back/src/main/java/ru/ambryo/gameplannerback/service/TelegramNotificationService.java`

В методе `buildGameNotificationMessage()`.
