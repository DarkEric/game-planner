**Вариант B - Вручную:**

## 🎯 Основные возможности

### Управление кампаниями
- Создание, редактирование, удаление кампаний
- Система вех для отслеживания прогресса
- Статусы: Active, On Hold, Completed
- Связывание игр с кампаниями

### Управление персонажами
- Создание персонажей при принятии приглашения
- Редактирование своих персонажей
- Сворачиваемая предыстория
- Отображение всех персонажей кампании

### Система ролей
- Мастер: полный контроль над кампанией
- Игрок: управление своим персонажем
- Возможность покинуть/выгнать из кампании

### Видимость
- Все кампании видны всем пользователям
- Сортировка по статусу
- Индикация роли пользователя
