# 🎉 Game Planner v1.5.0 - Campaign Management System

**Release Date:** November 20, 2025

## 🆕 Что нового

### 🎲 Система управления кампаниями

Теперь Game Planner поддерживает полноценное управление настольными кампаниями!

**Основные возможности:**
- 📝 Создание кампаний с названием и описанием
- 🎯 Система вех (milestones) для отслеживания прогресса
- 👥 Приглашение игроков с созданием персонажей
- ✏️ Редактирование кампаний и персонажей
- 🗑️ Удаление кампаний с подтверждением
- 📊 Отслеживание прогресса и статистики
- 🎮 Связывание игр с кампаниями

### 👤 Управление персонажами

**Создание и редактирование:**
- Создание персонажа при принятии приглашения в кампанию
- Поля: имя, класс, раса, уровень, предыстория
- Игроки могут редактировать своих персонажей
- Сворачиваемая предыстория для экономии места

**Отображение:**
- Список всех персонажей в кампании
- Цветные бейджи для быстрой идентификации
- Информация о классе, расе и уровне

### 🎭 Система ролей

**Мастер (Game Master):**
- Создание и настройка кампании
- Приглашение и удаление игроков
- Редактирование названия, описания, вех
- Изменение статуса кампании
- Удаление кампании

**Игрок (Player):**
- Просмотр информации о кампании
- Создание и редактирование своего персонажа
- Просмотр других персонажей
- Возможность покинуть кампанию

### 📈 Отслеживание прогресса

**Вехи (Milestones):**
- Настройка общего количества вех
- Отметка завершенных вех
- Визуальный прогресс-бар
- Процент выполнения

**Статистика игр:**
- Раздельный подсчет завершенных и запланированных игр
- История всех игр кампании
- Связь игр с прогрессом кампании

### 🌍 Видимость кампаний

**Все кампании видны всем пользователям:**
- Сортировка по статусу (ACTIVE → ON_HOLD → COMPLETED)
- Индикация вашей роли (Мастер/Игрок/Нет роли)
- Возможность присоединиться по приглашению
- Прозрачность для всего сообщества

## 📖 Как использовать

### Создание кампании

1. Перейдите на вкладку "Кампании"
2. Нажмите "Создать кампанию"
3. Заполните:
   - Название кампании
   - Описание
   - Количество вех (опционально)
4. Нажмите "Создать"

### Приглашение игроков

1. Откройте детали кампании
2. Нажмите "Пригласить игрока"
3. Выберите пользователя из списка
4. Игрок получит приглашение

### Принятие приглашения

1. Откройте кампанию, в которую вас пригласили
2. Нажмите "Принять приглашение"
3. Создайте персонажа:
   - Имя персонажа
   - Класс (например, Воин, Маг)
   - Раса (например, Человек, Эльф)
   - Уровень
   - Предыстория (опционально)
4. Нажмите "Создать персонажа"

### Связывание игры с кампанией

1. При создании игры выберите кампанию из списка
2. Игра будет отображаться в истории кампании
3. После проведения игры можно отметить прогресс вех

### Редактирование кампании

**Мастер может:**
- Изменить название и описание
- Настроить количество вех
- Отметить завершенные вехи
- Изменить статус (Active/On Hold/Completed)
- Удалить кампанию

**Игрок может:**
- Редактировать своего персонажа
- Покинуть кампанию

## 🔧 Технические детали

### Backend (Java/Spring Boot)

**Новые сущности:**
- `Campaign` - основная информация о кампании
- `CampaignPlayer` - связь игрока, персонажа и кампании
- `CampaignInvite` - приглашения в кампанию

**API эндпоинты:**
```
GET    /api/campaigns              - список всех кампаний
POST   /api/campaigns              - создание кампании
GET    /api/campaigns/{id}         - детали кампании
PUT    /api/campaigns/{id}         - обновление кампании
DELETE /api/campaigns/{id}         - удаление кампании
PUT    /api/campaigns/{id}/milestones - обновление вех
POST   /api/campaigns/{id}/invite  - приглашение игрока
POST   /api/campaigns/{id}/accept  - принятие приглашения
PUT    /api/campaigns/{id}/players/{playerId}/character - редактирование персонажа
DELETE /api/campaigns/{id}/leave   - покинуть кампанию
DELETE /api/campaigns/{id}/players/{playerId} - выгнать игрока
```

**Миграции Liquibase:**
- `012-create-campaign-invites.xml` - таблицы для кампаний

### Frontend (React)

**Новые компоненты:**
- `CampaignList.jsx` - список кампаний с карточками
- `CampaignDetails.jsx` - детальная информация о кампании
- `campaignApi.js` - API сервис для работы с backend

**Интеграция:**
- Добавлена вкладка "Кампании" в главное меню
- Связь с GameScheduler для создания игр в кампаниях
- Модальные окна для редактирования и подтверждений

## 💡 Примеры использования

### Для D&D кампании

1. Создайте кампанию "Curse of Strahd"
2. Установите 12 вех (по количеству глав)
3. Пригласите игроков
4. Игроки создают персонажей
5. Планируйте игры и связывайте с кампанией
6. Отмечайте прогресс после каждой сессии

### Для Pathfinder кампании

1. Создайте кампанию с описанием сюжета
2. Настройте вехи под ваш adventure path
3. Отслеживайте прогресс и статистику
4. Ведите историю всех игр

### Для нескольких кампаний

1. Создавайте разные кампании для разных систем
2. Игроки могут участвовать в нескольких кампаниях
3. Каждая кампания имеет свой прогресс и историю
4. Легко переключайтесь между кампаниями
