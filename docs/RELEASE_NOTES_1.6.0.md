## 📖 Как использовать

### Настройка уведомления об удалении из игры

1. Откройте настройки профиля
2. Перейдите в раздел "Telegram уведомления"
3. Найдите настройку "Исключили из игры"
4. Выберите:
   - **Получать** - будете получать уведомления при удалении из игры
   - **Не получать** - уведомления отключены

### Установка лимита участников

1. При создании игры заполните поле "Максимальное количество участников"
2. Игроки не смогут записаться, если лимит достигнут
3. Создатель игры не учитывается в лимите

### Автоматическое добавление игроков

1. При создании игры выберите игроков в списке участников
2. Включите опцию "Автоматически добавить выбранных игроков"
3. Игроки будут автоматически добавлены при создании игры

### Удаление игрока из игры

1. Откройте детали игры (только для организатора)
2. Найдите игрока в списке участников
3. Нажмите кнопку удаления
4. Игрок получит уведомление в Telegram (если включено)

## 🔧 Технические детали

### Backend (Java/Spring Boot)

**Новые возможности:**
- Метод `sendPlayerRemovedFromGameNotification` в `TelegramNotificationService`
- Поле `gameRemovedFromGame` в настройках уведомлений
- Поле `maxParticipants` в сущности `Game`
- Параметр `autoAddPlayers` в `CreateGameRequest`
- Метод `removePlayerFromGame` в `GameService`

**Миграции Liquibase:**
- `018-add-max-participants.xml` - добавление поля `max_participants` в таблицу `games`
- `019-remove-game-added-to-game.xml` - удаление столбца `game_added_to_game`
- `020-add-game-removed-from-game.xml` - добавление столбца `game_removed_from_game`

**API изменения:**
```
POST /api/games
  - Добавлен параметр maxParticipants (Integer, опционально)
  - Добавлен параметр autoAddPlayers (Boolean, опционально)
  - Добавлен параметр participantIds (List<Long>, опционально)

DELETE /api/games/{gameId}/players/{playerId}
  - Новый эндпоинт для удаления игрока из игры
```

### Frontend (React)

**Новые компоненты и функции:**
- Улучшенный `GameScheduler.jsx` с поддержкой лимита участников
- Обновленный `GameDetails.jsx` с функцией удаления игроков
- Настройка "Исключили из игры" в `TelegramNotificationsSettings.jsx`
- Визуальная индикация заполненности игры

## 💡 Примеры использования

### Ограничение количества участников

1. Создайте игру для D&D сессии
2. Установите лимит 5 участников (помимо мастера)
3. Игроки смогут записаться, пока не достигнут лимита
4. При попытке записи сверх лимита появится сообщение об ошибке

### Автоматическое добавление постоянной группы

1. Создайте игру для регулярной кампании
2. Выберите постоянных игроков
3. Включите "Автоматически добавить выбранных игроков"
4. Все игроки будут автоматически добавлены при создании

### Удаление игрока с уведомлением

1. Игрок не может прийти на игру
2. Организатор удаляет его из игры
3. Игрок автоматически получает уведомление в Telegram
4. Игрок видит информацию об игре и может при необходимости связаться с организатором
