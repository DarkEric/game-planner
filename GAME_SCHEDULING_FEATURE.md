# Функция планирования игр

## Описание
Добавлена возможность планирования игр с выбором даты, времени и участников.

## Функционал

### Интерфейс
- **Кнопка "Запланировать игру"** в левой панели профиля
- **Модальное окно** с двумя секциями:
  - Календарь для выбора даты и времени начала/конца игры
  - Топ-10 лучших временных слотов с максимальным количеством доступных игроков

### Возможности
1. Выбор даты из календаря текущего месяца
2. Ручной ввод времени начала и конца игры
3. Автоматический выбор участников из лучших слотов
4. Визуализация запланированных игр в основном календаре
5. Удаление игр (только создателем)

## Backend API

### Эндпоинты
- `POST /api/games` - создать игру
- `GET /api/games?startDate=...&endDate=...` - получить игры за период
- `GET /api/games/my` - получить мои предстоящие игры
- `POST /api/games/{gameId}/join` - записаться на игру
- `POST /api/games/{gameId}/leave` - покинуть игру
- `DELETE /api/games/{gameId}` - удалить игру (только создатель)

## База данных

### Таблицы
- `games` - информация об играх
- `game_participants` - связь игр и участников (many-to-many)

### Миграция
Файл: `008-create-games-table.xml`

## Frontend компоненты

### GameScheduler
Модальное окно для планирования игры с:
- Календарем на текущий месяц
- Полями ввода времени начала/конца
- Полями для названия и описания игры (необязательно)
- Списком топ-10 лучших слотов
- Кнопками "Отмена" и "Запланировать игру"

### GameDetails
Модальное окно с деталями игры:
- Название игры (если указано)
- Описание игры (если указано)
- Информация о времени начала, окончания и длительности
- Имя организатора
- Список участников с цветовыми метками
- Кнопки действий в зависимости от роли:
  - Создатель: "Удалить игру"
  - Участник: "Покинуть игру"
  - Не участник: "Записаться на игру"

### Интеграция в App.jsx
- Кнопка открытия планировщика
- Загрузка и отображение игр в календаре
- Открытие деталей игры по клику
- Запись/выход/удаление игр

## Использование

### Создание игры
1. Нажмите кнопку "🎲 Запланировать игру"
2. Выберите дату и время или кликните на один из предложенных слотов
3. (Опционально) Укажите название и описание игры
4. Нажмите "Запланировать игру"
5. Игра появится в календаре как событие

### Запись на игру
1. Кликните на игру в календаре
2. Откроется окно с деталями игры
3. Нажмите "Записаться на игру"
4. Ваша доступность автоматически проставится на время игры
5. Вы появитесь в списке участников

### Выход из игры
1. Кликните на игру, в которой вы участвуете
2. Нажмите "Покинуть игру"
3. Вы будете удалены из списка участников
4. Ваша доступность на время игры будет автоматически удалена

### Удаление игры
1. Кликните на игру, которую вы создали
2. Нажмите "Удалить игру"
3. Подтвердите удаление
4. Игра будет удалена для всех участников

## Технические детали

- Все даты хранятся в UTC на бекенде
- Конвертация в timezone пользователя происходит на фронтенде
- Игры отображаются как события в CalendarTimeline
- Автоматический подбор участников из доступных игроков в выбранном слоте
- При записи на игру автоматически проставляются TimeSlot на все часы игры
- При выходе из игры автоматически удаляются TimeSlot на все часы игры
- Создатель игры не может покинуть её, только удалить
- При удалении игры все участники теряют доступ к ней
