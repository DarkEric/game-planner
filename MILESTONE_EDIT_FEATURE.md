# Функция редактирования вех кампании

## Описание
Добавлена возможность редактировать как количество пройденных вех (completedMilestones), так и общее количество вех (totalMilestones) в прогрессе кампании.

## Изменения

### Backend

#### CampaignController.java
- Обновлен метод `updateMilestones()` для принятия двух параметров: `completedMilestones` и `totalMilestones`

#### CampaignService.java
- Обновлен метод `updateMilestones()` для обработки обоих параметров
- Добавлена валидация: оба параметра опциональны (могут быть null)
- Обновляются только те поля, которые переданы

### Frontend

#### campaignApi.js
- Обновлен метод `updateMilestones()` для отправки обоих параметров на сервер
- Параметры опциональны и могут быть undefined

#### CampaignDetails.jsx
- Добавлено состояние `editedTotalMilestones` для хранения редактируемого значения общего количества вех
- Переименовано `editedMilestones` в `editedCompletedMilestones` для ясности
- Обновлен UI для отображения двух полей ввода:
  - Поле "Пройдено" для completedMilestones
  - Поле "Всего" для totalMilestones
- Добавлена валидация: количество пройденных вех не может превышать общее количество
- Улучшен дизайн с подписями полей и лучшим расположением элементов

## Использование

1. Откройте детали кампании
2. В разделе "Прогресс кампании" нажмите на иконку редактирования (✏️)
3. Измените значения в полях "Пройдено" и/или "Всего"
4. Нажмите кнопку сохранения (💾) или отмены (❌)

## Валидация
- Количество пройденных вех не может быть больше общего количества
- Минимальное значение для пройденных вех: 0
- Минимальное значение для общего количества вех: 1
