# История изменений / Changelog

Все важные изменения проекта документируются в этом файле.

## [1.6.0] - 2025-01-XX

### ✨ Добавлено
- **Уведомление об удалении из игры** - Telegram уведомление "Ваша запись на игру была отменена" при удалении игрока организатором
  - Мягкая формулировка для комфортного восприятия
  - Настраиваемое уведомление (можно включить/выключить в настройках)
  - Информация об игре, времени и организаторе в уведомлении
- **Максимальное количество участников** - Возможность установить лимит участников для игры
  - Автоматическая проверка при записи на игру
  - Создатель не учитывается в лимите
  - Визуальная индикация заполненности игры
- **Автоматическое добавление игроков** - Опция автоматического добавления выбранных игроков при создании игры
  - Упрощает процесс планирования для организаторов
  - Гибкая настройка через параметр `autoAddPlayers`
- **Удаление игроков из игры** - Организатор может удалять игроков из игры
  - Автоматическая отправка уведомления удаленному игроку
  - Защита от удаления создателя игры

### 🔧 Улучшено
- Улучшена система персональных уведомлений Telegram
  - Поддержка cron-выражений для напоминаний о разметке времени
  - Гибкая настройка персональных уведомлений
  - Улучшенный интерфейс настроек Telegram уведомлений
- Оптимизирована обработка подсчета участников
- Улучшена работа с временными слотами игры

### 🐛 Исправлено
- Исправлена ошибка компиляции с final переменными в лямбда-выражениях
- Удалено избыточное уведомление "Добавили на игру" (не имело смысла, так как игрок сам записывается на игру)
- Улучшена обработка ошибок при отправке уведомлений

### 📚 Backend
- Добавлен метод `sendPlayerRemovedFromGameNotification` в `TelegramNotificationService`
- Добавлено поле `gameRemovedFromGame` в настройках уведомлений
- Добавлено поле `maxParticipants` в сущности `Game`
- Добавлен параметр `autoAddPlayers` в `CreateGameRequest`
- Добавлен метод `removePlayerFromGame` в `GameService`
- Добавлены миграции Liquibase: `018-add-max-participants.xml`, `019-remove-game-added-to-game.xml`, `020-add-game-removed-from-game.xml`
- Новый API эндпоинт: `DELETE /api/games/{gameId}/players/{playerId}`

### 📱 Frontend
- Улучшен `GameScheduler.jsx` с поддержкой лимита участников
- Обновлен `GameDetails.jsx` с функцией удаления игроков
- Добавлена настройка "Исключили из игры" в `TelegramNotificationsSettings.jsx`
- Визуальная индикация заполненности игры

## [1.5.1] - 2025-11-20

### 🐛 Исправлено
- **Загрузка данных игроков при навигации по календарю** - Исправлена проблема, когда при листании календаря или изменении количества видимых дней данные о доступности игроков не обновлялись
  - Теперь при изменении диапазона дат автоматически перезагружаются данные всех игроков
  - API запросы `/api/players` и `/api/players/me` теперь корректно учитывают параметры `startDate` и `endDate`
  - Улучшена синхронизация между видимым диапазоном календаря и загруженными данными

## [1.5.0] - 2025-11-20

### ✨ Добавлено
- **Управление кампаниями** - Полноценная система управления настольными кампаниями
  - Создание кампаний с названием, описанием и системой вех (milestones)
  - Приглашение игроков в кампанию с созданием персонажей
  - Принятие/отклонение приглашений игроками
  - Редактирование названия, описания и количества вех
  - Удаление кампаний с подтверждением
  - Отслеживание прогресса кампании (завершенные/общие вехи)
  - Связывание игр с кампаниями
  - Раздельный подсчет завершенных и запланированных игр
  
- **Управление персонажами** - Система персонажей для кампаний
  - Создание персонажей при принятии приглашения
  - Редактирование своих персонажей игроками
  - Сворачиваемая предыстория персонажей
  - Отображение списка персонажей в кампании
  
- **Система ролей в кампаниях** - Разделение прав доступа
  - Мастер (Game Master) - полный контроль над кампанией
  - Игрок (Player) - просмотр и управление своим персонажем
  - Возможность покинуть кампанию для игроков
  - Возможность выгнать игрока для мастера
  
- **Видимость кампаний** - Все кампании видны всем пользователям
  - Сортировка по статусу (ACTIVE → ON_HOLD → COMPLETED)
  - Индикация роли пользователя в кампании
  - Прогресс-бар для отображения прогресса вех

## [1.0.0] - 2024-11-16

### 🎉 Первый релиз

Первый стабильный релиз Game Planner - веб-приложения для планирования настольных игр с друзьями.

### ✨ Возможности

#### Основной функционал
- **Интерактивный календарь** - Отметка доступного времени drag-and-drop
- **Умный поиск слотов** - Автоматический поиск лучшего времени для всех игроков
- **Планирование игр** - Создание игр с названием, описанием и участниками
- **Поддержка часовых поясов** - Каждый видит время в своем часовом поясе
- **Система инвайтов** - Регистрация только по приглашениям
- **Автоочистка** - Автоматическое удаление старых игр (30+ дней)

#### Интерфейс
- **Темная тема** - Приятный для глаз темный интерфейс
- **Адаптивный дизайн** - Работает на любых экранах
- **Адаптивный календарь** - Показывает 7-21 день в зависимости от ширины экрана
- **Переключатель языка** - RU/EN локализация интерфейса (частичная)
- **Автопрокрутка** - Календарь автоматически прокручивается к 12:00

#### Технические возможности
- **JWT аутентификация** - Безопасная аутентификация пользователей
- **PostgreSQL база данных** - Надежное хранение данных
- **Docker развертывание** - Простая установка с Docker Compose
- **Автоматический HTTPS** - Интеграция с Caddy для production
- **Оптимизация API** - Объединение последовательных временных слотов

### 🛠 Технологии

**Backend:**
- Java 17 + Spring Boot
- PostgreSQL
- Liquibase миграции
- JWT аутентификация

**Frontend:**
- React 18
- Vite
- CSS Modules
- i18n поддержка

**Развертывание:**
- Docker & Docker Compose
- Caddy (автоматический HTTPS)

### 📦 Установка

```bash
git clone https://github.com/DarkEric/game-planner.git
cd game-planner
cp .env.example .env
docker-compose up -d
```

Откройте http://localhost и используйте инвайт-код: `FIRST-USER-INVITE-2025`
