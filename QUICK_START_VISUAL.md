# 🚀 Быстрый старт - Визуальный гайд

## За 3 шага к первой игре

```
┌─────────────────────────────────────────────────────────────┐
│  ШАГ 1: ЗАПУСК (2 минуты)                                   │
└─────────────────────────────────────────────────────────────┘

  💻 Установите Docker Desktop
     ↓
  📥 git clone https://github.com/DarkEric/game-planner.git
     ↓
  🚀 docker-compose up -d
     ↓
  🌐 Откройте http://localhost


┌─────────────────────────────────────────────────────────────┐
│  ШАГ 2: ПЕРВЫЙ ВХОД (1 минута)                              │
└─────────────────────────────────────────────────────────────┘

  🔑 Инвайт-код: FIRST-USER-INVITE-2025
     ↓
  👤 Создайте аккаунт
     ↓
  ✅ Войдите в систему


┌─────────────────────────────────────────────────────────────┐
│  ШАГ 3: ПЛАНИРОВАНИЕ (2 минуты)                             │
└─────────────────────────────────────────────────────────────┘

  📅 Отметьте свободное время (клик или протяните мышью)
     ↓
  👥 Пригласите друзей (создайте инвайт-коды)
     ↓
  🎮 Запланируйте игру (выберите из топ-10 слотов)
     ↓
  🎉 Готово!
```

## Основные действия

### 📅 Отметить время

```
СПОСОБ 1: Клик
┌──┐
│  │ ← Кликните на ячейку
└──┘
 ↓
┌──┐
│░░│ ← Ячейка отмечена
└──┘

СПОСОБ 2: Протянуть
┌──┬──┬──┐
│  │  │  │ ← Зажмите и протяните
└──┴──┴──┘
 ↓
┌──┬──┬──┐
│░░│░░│░░│ ← Несколько ячеек отмечены
└──┴──┴──┘
```

### 🎮 Создать игру

```
1. Нажмите "Запланировать игру"
   ↓
2. Выберите время:
   ┌─────────────────────────────┐
   │ Топ-10 лучших слотов:       │
   │ ○ Пт 18:00-21:00 (3/3)      │
   │ ○ Сб 19:00-22:00 (2/3)      │
   │                              │
   │ Или укажите вручную:         │
   │ Начало: [__:__]              │
   │ Конец:  [__:__]              │
   └─────────────────────────────┘
   ↓
3. Добавьте детали:
   ┌─────────────────────────────┐
   │ Название: D&D Session #42   │
   │ Описание: Продолжаем...     │
   └─────────────────────────────┘
   ↓
4. [Запланировать игру]
```

### 👥 Пригласить друга

```
1. "Мои инвайт-коды" → "+ Создать инвайт"
   ↓
2. Скопируйте код:
   ┌─────────────────────────────┐
   │ ABC123XYZ  [📋 Копировать]  │
   └─────────────────────────────┘
   ↓
3. Отправьте другу
   ↓
4. Друг регистрируется с этим кодом
```

## Цветовая схема

```
🟦 Синий    = Ваше свободное время
🟩 Зеленый  = Время других игроков
🟪 Фиолетовый = Пересечение (много игроков свободны)
🟥 Красный  = Запланированная игра
```
