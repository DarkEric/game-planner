# 🎉 Game Planner v1.7.0 - Improved Registration & Admin Features

**Release Date:** January 2025

## 🆕 Что нового

### 👤 Улучшенная регистрация пользователей

**Разделение логина и отображаемого имени:**
- Теперь при регистрации четко разделены понятия **логин** (username) и **отображаемое имя** (name)
- Поле "Логин" используется для входа в систему (уникальное, изменяется только администратором)
- Опциональное поле "Отображаемое имя" - как вас будут видеть другие пользователи
- Можно задать отображаемое имя при регистрации или позже в настройках профиля
- Если имя не указано, используется логин (обратная совместимость)

**Улучшенный UX регистрации:**
- Понятные подсказки для каждого поля
- Placeholder'ы с объяснениями
- Информация о том, что имя можно изменить позже в профиле

### 🔐 Сброс пароля

**Новая функциональность восстановления доступа:**
- Возможность запросить сброс пароля через Telegram бота
- Безопасная система токенов для сброса
- Удобный интерфейс подтверждения сброса пароля
- Улучшенная обработка ошибок и логирование

### 👨‍💼 Админ-панель

**Управление пользователями:**
- Функциональность удаления пользователей администратором
- Улучшенная логика назначения первого пользователя администратором
- Детальное логирование процесса инициализации админа
- Проверка существующих пользователей перед назначением прав

**Улучшения админ-сервиса:**
- Оптимизация зависимостей (удалены неиспользуемые автопривязки)
- Улучшенная обработка ошибок
- Более информативные логи

### 🎮 Улучшения управления играми

**Фильтрация и поиск:**
- Возможность получить список игр, созданных текущим пользователем
- Улучшенная фильтрация игр в компоненте деталей кампании
- Ассоциация игры с кампанией при создании
- Расширенное логирование для отладки

### 🔧 Технические улучшения

**Backend (Java/Spring Boot):**
- Обновлен `RegisterRequest` DTO с опциональным полем `name`
- Улучшен `AuthService` для поддержки отображаемого имени
- Новый сервис `PasswordResetService` для восстановления паролей
- Расширенный `AdminService` с функциональностью удаления пользователей
- Улучшенная конфигурация `WebMvcConfig`
- Оптимизация `TelegramNotificationService`

**Frontend (React):**
- Обновлена форма регистрации с разделением логина и имени
- Новый компонент `ResetPasswordModal` с улучшенным UX
- Улучшенный интерфейс админ-панели
- Оптимизированная фильтрация игр в `CampaignDetails`

## 📖 Как использовать

### Регистрация с отображаемым именем

1. При регистрации заполните поле **"Логин"** - это будет ваш уникальный идентификатор для входа
2. Опционально заполните **"Отображаемое имя"** - как вас будут видеть другие пользователи
3. Если имя не указано, будет использован логин
4. Имя можно изменить позже в настройках профиля

### Сброс пароля

1. На странице входа нажмите "Забыли пароль?"
2. Введите ваш логин
3. Если ваш аккаунт связан с Telegram ботом, код для сброса будет отправлен в Telegram
4. Введите код и новый пароль
5. Пароль успешно изменен!

### Удаление пользователя (только для администраторов)

1. Откройте админ-панель
2. Найдите пользователя в списке
3. Нажмите кнопку удаления
4. Подтвердите действие
